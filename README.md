# Aid Ship Manager

A JavaFX desktop application built for my Application Programming course at UTSA.

## Features
- List all aid ships and their details
- Find a ship by its registration number
- Delete a ship and save the change to a CSV file
- Display feedback for missing ships and invalid input

## Technologies
- Java
- JavaFX and FXML
- Maven
- CSV file handling

## What I learned
This project helped me connect object-oriented Java code to a graphical interface, separate the model from the controller and view, and preserve data between application sessions.
